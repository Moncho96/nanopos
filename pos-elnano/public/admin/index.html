Importar recetas
Sube un CSV para dar de alta recetas de varios productos de un jalón. Si el insumo no existe todavía, se crea solo con la unidad y costo que pongas.

Recuerda: la cantidad es por 1 pieza/unidad base del producto — si tiene variantes tipo "Orden" con multiplicador, ese multiplicador se aplica aparte (en Menú → 📋 de cada producto), no aquí.

Columnas requeridas (en este orden, con encabezado):
producto,insumo,unidad,cantidad,costo_unitario_insumo
Importar historial
Sube un archivo CSV con tus ventas anteriores. Cada fila es un producto dentro de un pedido — varias filas con el mismo "pedido_externo" se juntan en un solo pedido. Esto no descuenta inventario ni avisa a cocina, solo queda guardado en el Historial y cuenta para reportes de fechas pasadas.

Columnas requeridas (en este orden, con encabezado):
pedido_externo,fecha,hora,sucursal,cliente_nombre,tipo,metodo_pago,producto,variante,cantidad,precio_unitario
